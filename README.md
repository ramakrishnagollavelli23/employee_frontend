# Employee Management System

A Full Stack **Employee Management System** developed using **Java**, **Spring Boot**, **React.js**, and **MySQL**. This application enables efficient management of employee records through Create, Read, Update, and Delete (CRUD) operations using a scalable RESTful architecture.

---

## 📌 Features

- Employee Create, Read, Update, and Delete (CRUD) Operations
- RESTful API Integration
- Responsive User Interface
- MySQL Database Integration
- Layered Architecture
- Exception Handling and Input Validation
- Clean and Maintainable Code

## 🚀 Getting Started

### Prerequisites

- Java 17 or above
- Maven
- Node.js & npm
- MySQL
- Git

### Backend Setup

```bash
git clone https://github.com/ramakrishnagollavelli23/employee_backend.git
cd employee_backend
mvn spring-boot:run
```

### Frontend Setup

```bash
git clone https://github.com/ramakrishnagollavelli23/employee_frontend.git
cd employee_frontend
npm install
npm start
```

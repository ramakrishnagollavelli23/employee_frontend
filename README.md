# Employee Management System

A Full Stack Employee Management System developed using Java Spring Boot, React.js, and MySQL. The application enables efficient management of employee records through Create, Read, Update, and Delete (CRUD) operations.

## Features

- Employee CRUD Operations
- RESTful API Integration
- Responsive User Interface
- MySQL Database Integration
- Layered Architecture
- Clean and Maintainable Code

## Tech Stack

### Backend
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- REST API

### Frontend
- React.js
- JavaScript
- HTML5
- CSS3
- Bootstrap
